# Contributing

Use Node.js 22+ and pnpm 9.15.9. Read [AGENTS.md](AGENTS.md) and [the internal recipe](docs/ai/RECIPE.md).

Keep the first version conversation-only. Change the scenario prompt and public reference material without adding business tools, records, forms or persistence. Preserve source attribution, session lifecycle, explicit errors and credential boundaries.

Run pnpm run verify. For visible changes, inspect desktop/mobile direct entry, reload and inline startup error/retry states. Real speech and Docker checks are separate. Update README, RECIPE, architecture and affected docs with behavior changes. Commit, push and other remote operations require their own explicit authorization.
